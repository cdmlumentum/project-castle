# v0.26.2: guarded tracking and monotone profile alternative

The completed v0.26.1 trial followed the wrong isolated upper-guide branch.
The 1260 nm output raw packet already contained the intended fundamental:
its guide-aligned transverse-field similarity to the verified Block 1 mode is
0.99999920, versus 0.00906616 for the branch selected by the trial. The selected
branch has sampled upper-core intensity fraction 0.04122, versus 0.81471 for
the intended branch. These are electric-field tracking quantities, not power
coupling efficiencies.

The targeted comparison is in `diagnostics/block2_tracking_20261127/`.
Block 1 panels use its saved fields. The Block 2 output panel uses the original
checksummed raw-mode cache, matched to the published beta. The input packet was
reconstructed with one fresh FDE solve at the original settings. Total successful
diagnostic runtime was 41.42 s, inside the 60-solve/45-minute cap. No full block
was rerun to obtain the figure.

## Explicit alternative

`config/native_monotone.json` selects `optimizer.method=monotone_powell` and
`solver.tracking_method=guarded_translation_v1`. The original `bounded_powell`
and `legacy` tracking remain readable for reproducibility. Standalone native
`coordinate_pattern` bundles reject the new settings rather than silently
substituting a different algorithm.

- Native raw snapshots retain their SI field grids and isolated ridge center.
  Isolated references are interpolated into the current guide frame with zero
  padding. Coupled supermode fields remain in the laboratory frame.
- TE-ineligible, non-finite, low-overlap and flagged coefficient extractions do
  not become objective values or tracking references. A rejected jump can insert
  bounded intermediate z samples from the last accepted reference. Recovery
  depth is explicit; no tolerance or complex-kappa clipping is used.
- An independent endpoint preflight compares full-domain isolated betas with
  the verified Block 1 records before Powell. Every saved profile and midpoint
  grid also checks actual endpoint modes and detuning signs. The existing domain
  neff tolerance is retained.
- Stick-breaking coordinates order the cubic B-spline coefficients from each
  fixed start to fixed end. The nonnegative derivative basis guarantees a
  derivative with one sign everywhere. This constrains signed lateral offset,
  which still passes through zero; it does not constrain absolute separation
  to be monotone.
- Invalid candidates receive an infeasibility penalty, without a coefficient
  objective or publication. If no valid candidate exists, the run fails clearly.
  Returning a best valid candidate after an invalid optimizer termination is
  explicitly marked unconverged.
- Failed attempts now retain their own failed status and actual solve counts,
  including when an endpoint gate stops the run before publication.

Raw FDE physics, mesh, domain, trial mode count, optical tolerances, upper-minus-
lower detuning, fixed endpoints, principal/phase-followed complex coupling and
versioned handoffs are preserved. Changing selection and parameterization changes
source/cache identities; profile handoffs record the named alternative. Extra
recovery samples increase cost only when tracking fails. No speedup is claimed.

## Pilot and validation

`tools/prepare_tracking_pilot.py` clones an actual baseline configuration into a
separate directory, preserves its optical settings, and caps the pilot at six
objective evaluations, 120 fresh FDE solves or 45 minutes. It retains independent
midpoint checks at the original 1% tolerance. A longer run requires endpoint,
candidate and midpoint checks to pass; the helper never starts one automatically.

The field comparison already exposes a smaller unresolved domain discrepancy:
the recovered 1260 nm output neff is 1.75934606445 in the full domain versus
1.75932046709 in the verified compact domain. Their difference 2.55974e-5
exceeds the existing 2e-5 domain tolerance. The intended branch is recovered,
but field identity alone does not establish numerical domain convergence.

Offline regressions use explicitly synthetic translated fields and rejected
references. Licensed pilot evidence is reported separately. Execution, numerical
selection/extraction parity, optimizer termination, interpolation convergence
and physical device validation are distinct. No Block 0 certificate is applied.

The licensed pilot stopped at the endpoint gate after 213.407 s and seven
completed FDE calls (zero failed eigensolves). All four endpoint detuning signs
were correct. The 1340 nm output upper-guide discrepancy was 2.76332e-5;
its lower-guide discrepancy, 2.00686e-5, also narrowly exceeded tolerance.
No objective evaluation or physical midpoint check was reached. A longer run
was not started. See the saved pilot assessment and endpoint preflight report.

The MODE interpreter-only validation passed spline, PCHIP and complex-coupling
parity checks and synthetic standalone handoffs, without physical FDE solves.
